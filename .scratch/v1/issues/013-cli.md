# T-013: CLI surface

Status: ready-for-agent
Depends on: T-006, T-007, T-010

`ferry init | add | pair | share | status | conflicts list | ignore | daemon`.
Daemon mode = watch + continuous sync + LAN/relay connectivity. Single-shot
`ferry sync` for scripting. Output is machine-parseable with `--json`.
Install path: one-line script (curl | sh) plus Homebrew formula later;
Windows via cargo-installed binary initially.

Acceptance: from zero to two synced machines using only `--help`, in under
five minutes, on each OS (manual checklist scripted where possible).
