# 07: Centralized Device Daemon Supervisor

Status: ready-for-agent
Depends on: 03-folder-registry-persistence
Blocks: 08, 09
Wave: 2 (parallel with 05, 06)

## What to build

Implement the device-level daemon that owns multiple `SyncEngine` instances via the registry from ticket 03. Moves the IPC socket from per-folder to device-global and multiplexes UI commands.

## Scope

- Create `crates/ferry-daemon/src/supervisor.rs` (new) with `Supervisor`:
  - `fn new(home: PathBuf, identity: DeviceIdentity) -> Self`
  - `fn load_registry(&self) -> Result<FolderRegistry, RegistryError>` (delegates to 03)
  - `fn spawn_engines(&mut self) -> Result<(), SupervisorError>` — for each `FolderRecord`, create `EngineConfig { store_dir: record.path, tree_dir: record.path, .. }` and `SyncEngine::new` + `engine.start()`. Store `EngineHandle` map by `folder_id`.
  - `fn handle_register(&mut self, path: PathBuf) -> Result<FolderRecord, OpError>` — validate, register via 03, spawn one engine, bind its IPC handler.
  - `fn handle_remove(&mut self, folder_id: &str) -> Result<(), OpError>` — stop engine, remove from registry, close handle.
  - `fn get_status(&self, folder_id: Option<String>) -> Result<EngineSnapshot, OpError>` — if `folder_id` None, return aggregate or first; if Some, return that engine's snapshot.
  - Supervision: on engine panic/exit, restart with backoff, emit `UiEvent::Error { code: "engine-crashed" }`.
- Move IPC socket: `crates/ferry-ipc/src/paths.rs::default_socket_path()` already returns `$FERRY_HOME/daemon.sock` (verify and fix if still per-folder). For Windows, `\\.\pipe\ferry-daemon` singleton, not per-folder hash.
- Extend `crates/ferry-daemon/src/ipc/mod.rs` (or `server.rs`) to dispatch `ClientCommand::ListFolders`, `RegisterFolder`, `RemoveFolder` to `Supervisor`.
- Extend `crates/ferry-daemon/src/ui/backend.rs`: `DaemonIpcAdapter` implements `list_folders`, `register_folder`, `remove_folder` via IPC. `InProcessAdapter` delegates to `FolderRegistry` directly for headless fallback.
- `crates/ferry-daemon/src/main.rs`: on `ferry daemon` without folder args, run `Supervisor` with `home = ferry_home()`. With folder args, register them first then run supervisor. Preserve `ferry daemon --listen` single-folder mode as deprecated wrapper that registers then spawns.

## File ownership

Owned: `crates/ferry-daemon/src/supervisor.rs` (new), `crates/ferry-daemon/src/ipc/mod.rs` (dispatch arms only), `crates/ferry-daemon/src/main.rs` (central socket + supervisor wiring), `crates/ferry-daemon/src/ui/backend.rs` (only `list_folders`/`register_folder`/`remove_folder` impls), `crates/ferry-ipc/src/paths.rs` (socket path fix if needed), `crates/ferry-daemon/tests/supervisor_tests.rs` (new).

Do not touch `crates/ferry-tui/**`, `crates/ferry-daemon/assets/**`, `crates/ferry-crypto/**`, `crates/ferry-sync/src/pairing_transport.rs`.

## Notes

Engine handles are `Arc<EngineHandle>` so `UiState` can share them. Do not store `SyncEngine` itself, only `EngineHandle`. Use `tokio::task::JoinHandle` for supervision.
