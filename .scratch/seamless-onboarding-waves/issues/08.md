# 08: Zero-File In-Band Pairing Transport

Status: ready-for-agent
Depends on: 04-pairing-code-crypto, 07-centralized-daemon-supervisor
Blocks: none
Wave: 3 (parallel with 09)

## What to build

Wire the pairing code (04) and the supervisor (07) together over a network transport. Replace file-based `pair-offer/response/grant` movement with an in-band QUIC handshake over mDNS or relay rendezvous keyed by the short code.

## Scope

- Create `crates/ferry-sync/src/pairing_transport.rs` (new) with `PairingTransport`:
  - `fn create_session(&self, folder_id: String) -> Result<CreatePairingResponse, OpError>` — generate `PairingCode` via 04, store ephemeral `PairingSession { code, folder_id, expires_at, state: AwaitingPeer }` in memory (or `$FERRY_HOME/pairings.json`), advertise via `ferry-iroh` mDNS with service name `ferry-pair-<code>` and via relay rendezvous topic `code`.
  - `fn join_session(&self, req: JoinPairingRequest) -> Result<PairResult, OpError>` — dial by code: try mDNS first, then relay, establish QUIC stream, run three-way handshake `Offer→Response→Grant` over the stream (reuse `ferry-crypto::pairing::PairingOffer/Response/Grant` but over bytes, not files), persist wrapped FMK into `CONFIG_HEAD` via `ferry-folder::pairing::accept_complete` equivalent over stream.
- Extend `crates/ferry-iroh/src/rendezvous.rs` (new) or `crates/ferry-iroh/src/lib.rs` with `advertise(code)` / `discover(code)` helpers. If `ferry-iroh` already has discovery, reuse it; do not duplicate `MdnsSetting`.
- `crates/ferry-ipc/src/backend.rs`: Implement `FakeBackend::create_pairing_session` / `join_pairing_session` with in-memory rendezvous `HashMap<code, oneshot>`, so tests don't need network.
- `crates/ferry-daemon/src/ui/backend.rs`: `InProcessAdapter` and `DaemonIpcAdapter` delegate to `PairingTransport`.
- `crates/ferry-daemon/src/ui/server.rs`: expose `POST /api/pair/create` and `POST /api/pair/join` (or reuse existing `/api/share` / `/api/pair/accept` with code body).

## File ownership

Owned: `crates/ferry-sync/src/pairing_transport.rs` (new), `crates/ferry-iroh/src/rendezvous.rs` (new) or `crates/ferry-iroh/src/discovery.rs` (extend), `crates/ferry-crypto/src/folder_key.rs` (only handshake persistence), `crates/ferry-daemon/src/ui/server.rs` (only pairing routes), `crates/ferry-ipc/src/backend.rs` (only pairing session impls), `crates/ferry-sync/tests/pairing_transport_tests.rs` (new).

Do not touch `crates/ferry-tui/**`, `crates/ferry-daemon/assets/**`, `crates/ferry-daemon/src/registry.rs`, `crates/ferry-cli/src/bootstrap.rs`.
