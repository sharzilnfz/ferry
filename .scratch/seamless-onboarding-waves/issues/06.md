# 06: Web /api/fs/ls + Folder Picker Modal

Status: ready-for-agent
Depends on: 02-filesystem-backend-seam
Blocks: none
Wave: 2 (parallel with 05, 07)

## What to build

Implement the server-side filesystem explorer endpoint and the web picker modal. The endpoint reuses ticket 02's traversal guard. The frontend renders breadcrumbs, quick presets, and autocomplete without touching daemon internals.

## Scope

- `crates/ferry-daemon/src/ui/server.rs`: add `GET /api/fs/ls?path=<abs>` handler calling `backend.list_directory(path)`. Reuse `ferry-ipc` validation, add HTTP-level guard: if `path` missing, default to `ferry_home()`. On `path-traversal`, return 403 with `code: "path-traversal"`. On `bad-path`, 400.
- `crates/ferry-daemon/assets/app.js`: add picker modal (new section, not full rewrite) with:
  - `+ Add Folder` button wiring to `fetch("/api/fs/ls?path=" + encodeURIComponent(path))`
  - Breadcrumb nav (clickable segments), quick presets (Home, Projects, Desktop via `XDG` or `$HOME` hints), inline subfolder expansion
  - Live autocomplete on the path input (`input` event → debounce 150ms → `fetch` → suggestion list)
  - Secret-scan warning display if `POST /api/registry/register` (added in 07) returns `secrets-found` (render warning, show `Share Anyway` path)
- `crates/ferry-daemon/assets/index.html` and `style.css`: minimal modal markup/style, obsidian glass aesthetic consistent with existing dashboard.
- `crates/ferry-daemon/tests/server_fs_tests.rs` (new) for HTTP-level security.

## File ownership

Owned: `crates/ferry-daemon/src/ui/server.rs` (only `/api/fs/ls` route + handler), `crates/ferry-daemon/assets/app.js` (picker modal section), `crates/ferry-daemon/assets/index.html` (picker modal markup), `crates/ferry-daemon/assets/style.css` (picker styles), `crates/ferry-daemon/tests/server_fs_tests.rs` (new).

Do not touch `crates/ferry-tui/**`, `crates/ferry-daemon/src/registry.rs`, `crates/ferry-daemon/src/supervisor.rs`, `crates/ferry-crypto/**`.

## Security

- No `std::fs` in `server.rs` handler. All reads go through `backend.list_directory`. The handler only validates the query param and forwards.
- Reject `path` containing `%2e%2e` decoded traversal, null bytes, or `//`. Return 403/400 before calling backend.
- Auth: reuse existing token middleware. `/api/fs/ls` is `/api/*` so it inherits bearer token check. Integration test must assert 403 without token.
