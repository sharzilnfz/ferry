# 09: Auto-Bootstrap + Two-Minute E2E

Status: ready-for-agent
Depends on: 07-centralized-daemon-supervisor
Blocks: none
Wave: 3 (parallel with 08)

## What to build

Make frontends self-bootstrapping and deliver the two-command onboarding flow. This ticket owns the CLI bootstrap and the acceptance script. It does not own pairing transport (08), so the two can run in parallel.

## Scope

- Create `crates/ferry-cli/src/bootstrap.rs` (new) with `ensure_daemon(home: &Path) -> Result<PathBuf, BootstrapError>`:
  - Check if `$FERRY_HOME/daemon.sock` (or Windows pipe) responds to `ClientCommand::Ping` within 200ms.
  - If not, spawn `ferry daemon --home <home>` as detached child (or `supervisor` in-process if `--foreground`), wait for socket with exponential backoff up to 5s, return socket path.
  - On failure, return `OpError { code: "daemon-start-failed", hint: "check $FERRY_HOME permissions" }`.
- `crates/ferry-cli/src/commands/ui.rs`: before dispatching `ferry ui [--web|--tui|--gui]`, call `ensure_daemon`. If `ferry` invoked with zero args (no subcommand), default to `ferry ui` with auto-detected frontend (GUI if `DISPLAY`/`WAYLAND_DISPLAY` set, else Web, else TUI). Add `ferry --help` epilog documenting the two-minute path.
- `crates/ferry-cli/src/commands/share.rs` (extend) and new `crates/ferry-cli/src/commands/join.rs`:
  - `ferry share [FOLDER]` — validates folder, runs secret scan, calls `create_pairing_session` if 08 is available else falls back to file offer, prints `Share code: XXXX-XXXX (expires in 10m)` and QR.
  - `ferry join <CODE> [DEST]` — calls `join_pairing_session { code, target_dir }`, prints `Joined <folder_id> at <path>`.
  - Both respect `FERRY_HOME` isolation (tests use two temp homes).
- `scripts/zero-config-e2e.sh` (new): validates two-command flow across two `$FERRY_HOME` dirs:
  ```sh
  export FERRY_HOME_A=$(mktemp -d) FERRY_HOME_B=$(mktemp -d)
  ferry --home $FERRY_HOME_A init /tmp/proj-a && ferry --home $FERRY_HOME_A share /tmp/proj-a --json > /tmp/code.json
  CODE=$(jq -r .code /tmp/code.json)
  ferry --home $FERRY_HOME_B join $CODE /tmp/proj-b --json
  echo "hello" > /tmp/proj-a/hello.txt && sleep 2 && test -f /tmp/proj-b/hello.txt
  ```
  Script must be idempotent, `set -euo pipefail`, and use `cargo run --bin ferry` when binary not installed.

## Acceptance

- [ ] `cargo test -p ferry-cli` green.
- [ ] `ensure_daemon` when socket absent spawns daemon, `daemon.sock` appears within 5s, second call reuses existing socket (no second daemon).
- [ ] `ferry` with zero args in a tty launches the default frontend (test via `ferry --help` and `ferry --test` flag that exits after bootstrap without opening window).

## Notes

Use `std::process::Command::spawn` with `stdin: null` and `stdout: piped` to avoid blocking. On Windows, use `creation_flags: DETACHED_PROCESS`. Do not add `daemonize` crate dep; use std only.
