# 03: Folder Registry Persistence — folders.toml

Status: ready-for-agent
Depends on: 01-foundation-contracts
Blocks: 07
Wave: 1 (parallel with 02, 04)

## What to build

Implement the persistent folder registry that maps `FolderId → PathBuf` at `$FERRY_HOME/folders.toml`. No daemon, no engines, no IPC. Pure storage with atomic writes and validation. This isolates the hardest persistence invariant so Wave 2's supervisor can assume the registry is trustworthy.

## Scope

- Create `crates/ferry-daemon/src/registry.rs` (or `crates/ferry-folder/src/registry.rs` if the crate already owns folder bootstrap — pick one and document it in the PR description; do not create both).
- Implement `FolderRegistry` with:
  - `load(home: &Path) -> Result<Self, RegistryError>` — reads `folders.toml` if exists, else empty. Validates TOML schema, rejects duplicate `folder_id` or overlapping paths.
  - `save(&self, home: &Path) -> Result<(), RegistryError>` — atomic write via `tempfile` in same dir + `rename`, `fsync` dir.
  - `register(&mut self, path: PathBuf) -> Result<FolderRecord, RegistryError>` — validates absolute, exists, is dir, not inside another registered folder and does not contain one, generates `folder_id` if new (reuse `ferry-folder` logic).
  - `remove(&mut self, folder_id: &str) -> Result<(), RegistryError>`
  - `list(&self) -> &[FolderRecord]`
- Respect `FERRY_HOME` resolution via `crates/ferry-cli/src/home.rs::ferry_home()`. When `FERRY_HOME` is unset, fall back to `~/.ferry`.
- Define `RegistryError` with codes `bad-path`, `already-synced`, `not-found`, `corrupt-registry`, `io`.

## File ownership

Owned: `crates/ferry-daemon/src/registry.rs` (new) OR `crates/ferry-folder/src/registry.rs` (new) — choose one, not both — plus `crates/ferry-folder/tests/registry_tests.rs` or `crates/ferry-daemon/tests/registry_tests.rs` (new). Also owns `crates/ferry-ipc/src/registry.rs` read-only? No, read-only. Only write the new registry module.

Do not touch `crates/ferry-ipc/src/backend.rs` (except reading types), `crates/ferry-crypto/**`, `crates/ferry-tui/**`, `crates/ferry-daemon/src/supervisor.rs`, `crates/ferry-daemon/src/ui/server.rs`.

## Acceptance

- [ ] `cargo test -p ferry-folder -p ferry-daemon` green.
- [ ] Round-trip: `register("/tmp/a")`, `save`, `load` returns one record with same `folder_id` and RFC3339 `added_at`.
- [ ] Validation: `register("/tmp/a/b")` when `/tmp/a` already registered returns `already-synced`. Vice versa also rejected.
- [ ] Atomicity: kill -9 mid-`save` leaves either old or new `folders.toml`, never half-written (test via `tempfile` + manual `open` + `write` half then `load`).
- [ ] Corrupt TOML (`folders.toml` with `folder_id = 123`) returns `corrupt-registry` with `hint: "fix or delete $FERRY_HOME/folders.toml"`, never panics.
- [ ] Concurrent `register` from two processes serializes via file lock or `rename` semantics; second writer sees first's record on `load`.
- [ ] `list` sorted by `added_at` asc for deterministic UI.

## Notes

Do not spawn any `SyncEngine`. Do not bind any socket. This ticket is storage only. The supervisor (ticket 07) will own engine lifecycle.
