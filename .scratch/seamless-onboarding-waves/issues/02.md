# 02: Filesystem Backend Seam — list_directory

Status: ready-for-agent
Depends on: 01-foundation-contracts
Blocks: 05, 06
Wave: 1 (parallel with 03, 04)

## What to build

Implement the filesystem traversal seam so TUI and Web pickers can browse securely. This is the security-critical ticket. Path traversal defense must land here and be reused by ticket 06.

## Scope

- `crates/ferry-ipc/src/backend.rs`: Implement `FakeBackend::list_directory` with an in-memory directory tree for tests. Implement `InProcessAdapter::list_directory` with real `std::fs::read_dir` respecting:
  - Symlink detection (`is_symlink` via `symlink_metadata`)
  - Git repo detection (`is_git_repo` if child `.git` exists)
  - Already-synced detection by checking ancestor/descendant overlap with `FolderRegistry` (read-only, loaded from `$FERRY_HOME/folders.toml` if present, otherwise empty)
  - Path normalization (NFC, `..` resolution, no `//`, absolute only)
- `crates/ferry-daemon/src/ui/backend.rs`: Delegate `list_directory` through `AutoBackend` / `DaemonIpcAdapter` to IPC, with boundary validation. No duplicate `read_dir` logic here.
- `crates/ferry-ipc/src/protocol.rs`: Wire `ClientCommand::ListDirectory { path }` and `DaemonMessage::DirectoryListing`.
- Add `crates/ferry-daemon/tests/fs_backend_tests.rs` (new) and extend `crates/ferry-ipc/tests/backend_tests.rs`.

## File ownership

Owned: `crates/ferry-ipc/src/backend.rs` (only `list_directory` impl blocks), `crates/ferry-daemon/src/ui/backend.rs` (only `list_directory` delegation), `crates/ferry-daemon/tests/fs_backend_tests.rs` (new), `crates/ferry-ipc/tests/backend_tests.rs` (append).

Do not touch `crates/ferry-folder/**` registry persistence, `crates/ferry-crypto/**`, `crates/ferry-tui/**`, `crates/ferry-daemon/src/supervisor.rs`.

## Security

- Reject `..` traversal that escapes `FERRY_HOME` or the requested root. Return `OpError { code: "path-traversal", hint: "path escapes allowed root" }`.
- Reject non-absolute paths with `bad-path`.
- On `permission-denied`, return typed `OpError` with `hint: "check folder permissions"`, never panic.
- `FakeBackend` must also enforce the same error codes so TUI/Web tests exercise the guard without touching disk.

## Acceptance

- [ ] `cargo test -p ferry-ipc -p ferry-daemon` green.
- [ ] `FakeBackend` lists an in-memory tree: `is_dir`, `is_symlink`, `is_git_repo`, `is_already_synced` correct per fixture.
- [ ] `InProcessAdapter` lists a real temp dir with 20 entries, correctly classifying symlink and git repo.
- [ ] Path traversal exploit (`/tmp/../etc/passwd`, `../../`) returns `path-traversal` error, not a listing.
- [ ] IPC round-trip: `ClientCommand::ListDirectory` serializes and deserializes, `DaemonIpcAdapter` forwards to daemon and returns `DirectoryListing` without re-reading disk.
- [ ] No new `read_dir` logic outside `ferry-ipc` / `InProcessAdapter`. `ferry-daemon` reuses validation via a shared `validate_path` helper in `ferry-ipc`.

## Comments

Keep `DirectoryEntry` ordering stable (sort by `is_dir` desc, then `name` asc) so TUI snapshots are deterministic.
