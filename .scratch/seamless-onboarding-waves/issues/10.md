# 10: GUI Native Folder Picker (Optional, Stretch)

Status: ready-for-agent
Depends on: 02-filesystem-backend-seam
Blocks: none
Wave: 2 (parallel with 05, 06, 07) — pick up if 05 or 06 finishes early

## What to build

Add native OS folder chooser to `ferry-gui` via `rfd`. This is a stretch ticket. It must not block Waves 3. If unstaffed, the feature ships without it and Web/TUI pickers are sufficient.

## Scope

- Add `rfd = { version = "0.14", optional = true }` to `crates/ferry-gui/Cargo.toml` behind `gui` feature.
- `crates/ferry-gui/src/picker.rs` (new) with `fn pick_folder_async() -> Option<PathBuf>` using `rfd::AsyncFileDialog::pick_folder().await` via `tokio::task::spawn_blocking`.
- Wire in `crates/ferry-gui/src/app.rs`: `Select Folder` button calls `pick_folder_async`, on `Some(path)` calls `backend.register_folder(path)`.
- Handle headless: if `rfd` returns `None` (cancelled) or `DISPLAY` absent, show inline error, do not crash.

## File ownership

Owned: `crates/ferry-gui/Cargo.toml` (rfd dep), `crates/ferry-gui/src/picker.rs` (new), `crates/ferry-gui/src/app.rs` (only `Select Folder` wiring), `crates/ferry-gui/tests/picker_tests.rs` (new).

Do not touch `crates/ferry-tui/**`, `crates/ferry-daemon/**`, `crates/ferry-crypto/**`.

## Acceptance

- [ ] Clicking `Select Folder` opens native dialog on macOS/Linux/Windows when `gui` feature is enabled.
- [ ] Selecting a folder calls `register_folder` and shows success; cancelling does nothing.
- [ ] `cargo test -p ferry-gui` passes with `#[ignore]` on the native dialog test when `DISPLAY` absent.

## Notes

This ticket is explicitly non-blocking. Mark `wontfix` if capacity is tight.
