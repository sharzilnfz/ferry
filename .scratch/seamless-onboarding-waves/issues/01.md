# 01: Foundation — Filesystem, Registry, and Pairing Contracts

Status: ready-for-agent
Depends on: none
Blocks: 02, 03, 04
Wave: 0

## What to build

Define the domain types and `UiBackend` trait extensions that unblock all later waves. No filesystem reads, no daemon, no crypto logic beyond types. This is the only ticket that touches the trait signature, so later waves never conflict on `backend.rs`.

## Scope

- Create `crates/ferry-ipc/src/fs.rs` with `DirectoryEntry`, `ListDirectoryRequest`, `ListDirectoryResponse`.
- Create `crates/ferry-ipc/src/registry.rs` with `FolderRecord`, `FolderRegistry` (TOML serde).
- Create `crates/ferry-ipc/src/pairing.rs` or extend existing with `CreatePairingRequest`, `CreatePairingResponse`, `JoinPairingRequest`, `PairingCode` newtype.
- Extend `crates/ferry-ipc/src/backend.rs` with six new methods on `UiBackend` as signatures only, each defaulting to `Err(OpError::not_found("not-implemented", ...))` in `FakeBackend` so tests compile but fail loudly.
- Extend `crates/ferry-ipc/src/protocol.rs` with `ClientCommand` / `DaemonMessage` variants for the six methods and their error codes.
- Add `crates/ferry-ipc/tests/contract_tests.rs` verifying serde round-trips and error code table.

## File ownership

Owned: `crates/ferry-ipc/src/fs.rs` (new), `crates/ferry-ipc/src/registry.rs` (new), `crates/ferry-ipc/src/pairing.rs` (new or extended), `crates/ferry-ipc/src/backend.rs` (trait signatures only), `crates/ferry-ipc/src/protocol.rs` (variants only), `crates/ferry-ipc/tests/contract_tests.rs` (new).

Do not touch `crates/ferry-daemon/**`, `crates/ferry-tui/**`, `crates/ferry-crypto/**` beyond reading.

## Acceptance

- [ ] Types compile with `cargo test -p ferry-ipc --lib` and `cargo clippy -p ferry-ipc`.
- [ ] `UiBackend` has `list_directory`, `list_folders`, `register_folder`, `remove_folder`, `create_pairing_session`, `join_pairing_session` with `BoxFuture` signatures matching the spec domain model.
- [ ] `FakeBackend` implements all six with `not-implemented` errors, so downstream tests can `#[should_panic]` or assert error codes.
- [ ] Serialization tests for `DirectoryEntry`, `FolderRecord`, `CreatePairingRequest` round-trip via JSON and TOML (for `folders.toml`).
- [ ] `crates/ferry-ipc/tests/contract_tests.rs` passes, asserting error codes `bad-path`, `path-traversal`, `already-synced`, `pairing-expired`.

## Notes

Keep structs `Clone + Debug + Serialize + Deserialize + PartialEq`. Fields use `PathBuf` absolute only, validated later in Wave 1. No `unwrap()` in constructors.
