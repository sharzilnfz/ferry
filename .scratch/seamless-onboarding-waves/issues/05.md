# 05: TUI Filesystem Explorer Widget

Status: ready-for-agent
Depends on: 02-filesystem-backend-seam
Blocks: none
Wave: 2 (parallel with 06, 07)

## What to build

Implement the interactive filesystem browser inside `ferry-tui`. Users press `A` or `O` to open a modal, navigate with arrows/`Enter`/`..`, filter by typing, `Space` to select. Wired to `UiBackend::list_directory`, tested against `FakeBackend`.

## Scope

- Create `crates/ferry-tui/src/picker.rs` (new) with `PickerState` state machine:
  - `current_path: PathBuf`, `entries: Vec<DirectoryEntry>`, `cursor: usize`, `filter: String`, `loading: bool`
  - `fn open(path: Option<PathBuf>)`, `fn move_up/down`, `fn enter() -> Option<PathBuf>`, `fn go_parent()`, `fn apply_filter(s: &str)`, `fn selected() -> Option<&DirectoryEntry>`
- Render in `crates/ferry-tui/src/ui.rs` as a centered modal with folder icons, `..` parent row, breadcrumb bar, `is_git_repo` badge, `is_already_synced` dimming.
- Wire in `crates/ferry-tui/src/app.rs`: handle `KeyCode::Char('a'|'A'|'o'|'O')` to open picker, `Esc` to close, `Space`/`Enter` to select and emit `register_folder` (or callback to caller). Do not implement `register_folder` handling here beyond calling the backend; the registry work is ticket 07's concern — on select, emit an event and close the modal.
- Add `crates/ferry-tui/tests/picker_tests.rs` (new) simulating key events against `FakeBackend`.

## File ownership

Owned: `crates/ferry-tui/src/picker.rs` (new), `crates/ferry-tui/src/ui.rs` (picker modal rendering only), `crates/ferry-tui/src/app.rs` (only `A`/`O`/`Space`/`Esc` arms for picker), `crates/ferry-tui/tests/picker_tests.rs` (new).

Do not touch `crates/ferry-ipc/src/backend.rs` (read-only trait), `crates/ferry-daemon/src/registry.rs`, `crates/ferry-daemon/src/ui/server.rs`, `crates/ferry-crypto/**`.

## Acceptance

- [ ] `cargo test -p ferry-tui` green.
- [ ] Keyboard simulation: open via `A`, arrow down twice, `Enter` into a subdir, verify `current_path` updated and `entries` re-fetched from `FakeBackend`.
- [ ] Filter: typing `pro` narrows entries to those containing `pro` case-insensitive, `Esc` clears filter.
- [ ] Selection: cursor on a dir, `Space` returns the `DirectoryEntry` with `is_dir == true`. Cursor on a file does nothing.
- [ ] Already-synced dirs are dimmed and `Space` on them shows `hint: "already synced"` without calling `register_folder`.
- [ ] Headless fallback: when `!atty::is(Stdin)` (or `TERM=dumb`), `A`/`O` does nothing and `app.rs` returns `OpError { code: "no-tty", hint: "pass explicit path" }`.

## Notes

Reuse `02`'s `validate_path` indirectly via `list_directory`. No direct `std::fs` in `ferry-tui`. All filesystem access goes through `UiBackend`.
