# 04: Short Pairing Code Crypto

Status: ready-for-agent
Depends on: 01-foundation-contracts
Blocks: 08
Wave: 1 (parallel with 02, 03)

## What to build

Implement the short pairing code primitive in `ferry-crypto`. No network, no folder, no daemon. Pure entropy → code → verify with checksum and expiry. This isolates the crypto binding so ticket 08 can focus on transport.

## Scope

- Create `crates/ferry-crypto/src/pairing_code.rs` (new) with `PairingCode` newtype.
- Implement `PairingCode::generate<R: Rng>(rng: &mut R) -> Self` — 128-bit entropy, encode as either:
  - 6-word BIP39-like wordlist (2048 words, 11 bits each, 66 bits + 6-bit checksum) padded to 6 words, or
  - 6-char base32 with 20-bit checksum if wordlist is not yet vendored.
  Pick one and document the choice in a `docs/adr/0006-pairing-code.md` stub. Do not implement both.
- Implement `fn verify(&self, input: &str) -> bool` using `subtle::ConstantTimeEq` for the checksum path, and `fn as_str(&self) -> &str`.
- Add `expiry` handling: `PairingCode` paired with `expires_at: SystemTime` (24h default) checked via `is_expired()`.
- Extend `crates/ferry-crypto/src/pairing.rs` only to expose `PairingCode` in the public API, no wire protocol changes.
- Add `crates/ferry-crypto/tests/pairing_code_tests.rs` with vectors.

## File ownership

Owned: `crates/ferry-crypto/src/pairing_code.rs` (new), `crates/ferry-crypto/src/pairing.rs` (re-export only), `crates/ferry-crypto/tests/pairing_code_tests.rs` (new), optional `docs/adr/0006-pairing-code.md` (new).

Do not touch `crates/ferry-ipc/**`, `crates/ferry-daemon/**`, `crates/ferry-tui/**`, `crates/ferry-sync/**`.

## Acceptance

- [ ] `cargo test -p ferry-crypto` and `cargo clippy -p ferry-crypto` green.
- [ ] `generate` produces 6 words/chars, each verify round-trips, and `verify("wrong-code")` is false.
- [ ] Checksum: flipping one character/word fails verification with `pairing-not-found` equivalent, not silent accept.
- [ ] Constant-time: `verify` uses `ct_eq`, not early-return `==`. Grep for `==` in the verify path fails CI.
- [ ] Entropy: 1000 generated codes have > 900 unique values (collision bound test).
- [ ] Expiry: `is_expired()` true after `expires_at` + 1s, false before. No `SystemTime::now()` in the type itself; caller passes `now`.

## Notes

Wordlist should be `static` and `&'static [&'static str]`, not allocated per call. Use existing `rand` 0.8 already in workspace, no new dep.
